## 🎯 Key Features

### 📖 Seven-Section Learning Structure
Every topic in the app follows a consistent, proven learning framework:

1. **Conceptual Overview** — Plain-language explanations of core concepts
2. **Process Flow** — Step-by-step business process workflows with visual diagrams
3. **Real-Life Business Scenario** — Practical, industry-relevant examples with business data
4. **Discovery Questions** — 5-7 critical workshop questions for stakeholder engagement
5. **Configuration Guide** — D365 setup steps with navigation paths
6. **Expert Tips & Common Pitfalls** — Best practices and lessons learned
7. **Sample UAT Data** — Test data for validating configurations

The app includes 10+ functional modules covering:
- **Finance Basics for ERP** — Accounting fundamentals (6 topics)

- **Procurement & Payables** — P2P process and vendor management (7 topics)

- **Supply Chain Execution** — Warehousing and fulfillment (5 topics)
- **And more...** Fully expandable module structure

### 🔍 Smart Navigation

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No installation or server required — fully self-contained

### Installation

1. **Download** the `d365_learning_coach_FINAL__2_.html` file
2. **Save** it to your computer
3. **Open** the file in any web browser
4. **Start Learning** — No setup needed!

### Basic Navigation

1. **Browse Modules** — Click module cards on the home page or expand the sidebar
2. **Explore Topics** — Select a module to view all topics
3. **Learn** — Click any topic to access the full seven-section learning guide
4. **Navigate** — Use Previous/Next buttons to move between topics
5. **Search** — Use the sidebar search bar to quickly find modules

## 📝 Topic Structure Explained

### Example: "Chart of Accounts" Topic

**1. Conceptual Overview**
- What is a Chart of Accounts?
- Why is it important in D365?
- Core principles and foundational concepts

**2. Process Flow**
```
Define Structure → Set Main Accounts → Configure Dimensions → 
Assign Ledger Accounts → Validation & Testing
```

**3. Real-Life Business Scenario**
- Example: Multi-division manufacturing company
- Business context and specific requirements
- Financial data and GL mapping impact

**4. Discovery Questions**
- What are your main business divisions?
- Do you require cost center tracking?
- How do you handle inter-company transactions?
- (*5-7 total questions*)

**5. Configuration Guide**
- Navigation path: General Ledger → Chart of Accounts → Main Accounts
- Setup steps and configuration options
- Best practices for structure design

**6. Expert Tips & Common Pitfalls**
- ✅ Always validate account combinations before go-live
- ❌ Don't overlook elimination accounts for consolidation

**7. Sample UAT Data**
- Test accounts, dimensions, and combinations
- Validation scenarios and expected results
